# v0.1.13 – a munkamenet teendői és állapota

**Verzió:** Android app **v0.1.13** (`appVersionName = "0.1.13"`)
**Ág:** `wip/v0.1.13-tor` → beolvasztva a `feature/android-app` ágba (a `main` ágon nincs Android-kód)

## Kiinduló állapot (a munkamenet előtt)

- Kész volt a WIP ágon: induláskori Orbot-ellenőrzés, `tor/TorSupport.kt` (Orbot-segédek, `TorWebProxy`, `TorProbe`),
  a bal fiók „Tor” csoportja (TOR / ONION / TORLAN), `ui/OnionIcon.kt`, `prefs.webTorMode`.
- Nem volt bekötve: a hagyma ikon, a `TorWebProxy`, a `webTorMode`, az `Orbot.openApp` / `requestStart`.
- Hiba volt: `ssh://192.168.0.1` beírásából `https://ssh://192.168.0.1` lett; egy oldal nem-webes linkje csendben elnyelődött.

## Feladatok

### 1. Eszközök panel – ✅ kész

- [x] Jobb fiók: új **router ikon** (`Icons.Filled.Router`) közvetlenül a Beállítások alatt, a Névjegy fölött
  (`ui/DrawerSystem.kt` → `RightDrawerPanel(onDevices)`).
- [x] Új képernyő `Screen.DEVICES` (`MainActivity.kt`), új fájl `ui/DevicesPanel.kt` (`StripedPanel`, felül FRISSÍTÉS).
- [x] Felül középre igazított gyorsgombok, a gombon csak a cím vége: `…0.1 …1.1 …2.1` / `…0.255 …1.255 …2.255`.
  Koppintásra a `LocalOpenLink` nyitja meg `http://192.168.x.y/` címmel → a Linkek kezelése (belső/külső/kérdez) szerint.
- [x] Alattuk a jelenlegi hálózat elmentett eszközei: `hub.loadAddresses(true)`, csak `Kind.LAN`, kattintható címekkel
  (a Webolvasó `AddressRow` sora `internal` lett, azt használja).

### 2. Hagyma (Tor) gomb a Webolvasóban – ✅ kész

- [x] `ui/WebReaderPanel.kt`: a LISTA · KÖNYV · SSH sor 4. gombja az `OnionIcon`; kijelölt, ha a Tor-mód aktív.
- [x] Bekapcsolás: Orbot telepítve? → proxy fut? → ha nem, `Orbot.requestStart`, majd max. 15 s várakozás →
  ha így sem: üzenet + párbeszédablak (ORBOT MEGNYITÁSA / TELEPÍTÉS → `Orbot.openApp`, ami Play Áruházba esik vissza).
  Siker esetén `TorWebProxy.enable(...)`, majd újratöltés. Kikapcsolás: `TorWebProxy.disable(...)`, újratöltés.
- [x] Régi WebView (nincs `PROXY_OVERRIDE`): üzenet, a mód nem kapcsol be.
- [x] Állapot: `prefs.webTorMode` (a `MainActivity` tartja, `torMode` / `onTorModeChange` paraméterekkel).
- [x] Tor-módban felirat: a forgalom az Orbot proxyján megy, a helyi címek kivételek.
- [x] Visszaállítás a panel megnyitásakor: a proxy-felülírás app-újraindításkor elvész, ezért a mentett Tor-módot a
  panel újra beállítja, és az induló címet csak utána tölti be; ha az Orbot nem fut, a mód kikapcsol és az oldal
  nem töltődik be (nem megy ki kérés Tor nélkül).
- [x] `.onion` bevitel → `http://` (nem `https://`).

### 3. Nem-webes címek – ✅ kész

- [x] `nonWebScheme()`: minden nem http/https séma (`ssh://`, `telnet://` …) felismerése; a `normalizeWebInput` ezekre
  üres címet ad (nem lesz `https://ssh://…`).
- [x] Címsorból és oldalon lévő linkből is: az **SSH-nézet** (`ReaderMode.SSH`) nyílik, felül rövid figyelmeztető üzenettel.
- [x] A címben lévő jelszó (`ssh://user:jelszo@host`) az üzenetben és a naplóban `***`.

## Telefonos ellenőrzés (még hátravan – a CI csak a fordítást ellenőrzi)

| Eset | Elvárt |
|---|---|

| Hagyma, Orbot telepítve, de leállítva | „indítást kérek…”, 15 s után üzenet + ORBOT MEGNYITÁSA (ha az Orbot elindul, magától bekapcsol) |
| Hagyma, Orbot fut | felirat megjelenik, az oldal újratöltődik; check.torproject.org → „Congratulations” |
| Tor-mód + `192.168.x.x` oldal | közvetlenül nyílik (kivétel) |
| Tor-mód + `2gzyxa5…onion` | megnyílik |
| App újraindítás bekapcsolt Tor-móddal | Webolvasó megnyitásakor visszakapcsol; ha az Orbot nem fut: KI + üzenet, oldal nem töltődik |
| `ssh://192.168.0.1` a címsorban | SSH-nézet + üzenet, NEM `https://ssh://…` |
| `ssh://root:titok@10.0.0.5` | az üzenetben/naplóban `root:***@` |
