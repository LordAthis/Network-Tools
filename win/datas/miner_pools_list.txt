5. MEGJEGYZESEK A DIAGNOSZTIKAI SCRIPTHEZ
--------------------------------------------------------------------------------
- Kimenő ESTABLISHED kapcsolat 3333/443/25 portra + ismert pool domain/IP = erős miner jel
- Helyi 4028/4433 nyitott port + JSON API válasz = helyi ASIC jelenlét
- A pool IP-k gyakran változnak → domain alapú + SNI/Host fejléc figyelés jobb, mint tiszta IP lista
- CGNAT / mobilnet esetén a pool felé menő kapcsolat akkor is látszik a helyi gépen/netstat-ban, ha a miner más eszközön van (ha a router NAT-ol)
